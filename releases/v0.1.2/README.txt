Refreshy v0.1.2 — Windows x64 (unpacked build)

HOW TO RUN — 4 steps, no commands except one copy line:

1. Download BOTH parts into the same folder:
   - Refreshy-v0.1.2-win-x64.zip.part00
   - Refreshy-v0.1.2-win-x64.zip.part01
   (use the "Raw" / download button on each file's page on GitHub)

2. Rejoin them: open Command Prompt in that folder and run:
   copy /b Refreshy-v0.1.2-win-x64.zip.part00+Refreshy-v0.1.2-win-x64.zip.part01 Refreshy-v0.1.2-win-x64.zip

3. Right-click Refreshy-v0.1.2-win-x64.zip → Extract All.

4. Open the extracted win-unpacked folder and double-click Refreshy.exe.

CHECK: the home screen must show "Refreshy v0.1.2" under the headline.
If Windows SmartScreen appears: click "More info" → "Run anyway" (this build is not code-signed).

If buttons still do nothing on a build that shows v0.1.2: a red panel at the
bottom of the window contains the exact error — copy it and report it.
